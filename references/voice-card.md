# Voice Card schema and bounded onboarding

Read only for creating or updating a profile, or when an existing profile lacks a relevant register.

## Sampling

Use samples the user authored, not received messages or model drafts mistaken for their writing. Prefer recent and diverse audience contexts. Record channel, audience category, approximate date, and provenance without collecting unrelated private content. Ownership alone does not prove authorship.

If the user authorizes source collection, define services, folders or queries, date range, and maximum sample count. Use only available authorized services. Missing access is a gap to report, not a reason to silently scan elsewhere. Request pasted samples only for relevant missing contexts.

Show the proposed card and ask what is wrong before treating it as approved. Keep the reviewed wording unchanged when saving. Refresh only on request; show the changed sections. An unseen format gets a provisional register extrapolated from similar samples, not a claim of an exact match.
