# On-demand reference map

Use only the resources matching the current task. The hub and writing quality gate govern output modes, preservation, and exceptions when an older example is more prescriptive.

- `pattern-index.md`: select an original pattern family and its separately preserved reference.
- `pattern-background.md`: interpret pattern provenance and model-era limitations.
- `voice-calibration.md`: calibrate against supplied samples and regional variety; no private-source collection.
- `voice_guide.md`: when correct prose still feels flat, preserve supported personality rather than invent experiences.
- `ai_patterns.md`: compact five-category review when useful, not an automatic second rewrite.
- `before_after_examples.md`: consult specific examples for an identified defect.
- `worked-example.md`: multi-pattern demonstration; its staged output is not the default.
- `guide-mode.md`: requested named tone modes or a full humanizer guide/document. Full-catalog requirements apply to full guides, not ordinary edits.
- `linked-workflow.md`: voice-matching and slop-rubric modes with route examples.
- `voice-card.md`: Voice Card schema and bounded onboarding.
- `slop-source-guide.md`, `slop-eval.md`: preserved original no-ai-slop guide and acceptance rubric.
- `writing-indicators.md`: comprehensive review catalog or a relevant category.
- `writing-quality-gate.md`: substantial writing and preservation review.
- `registers-and-examples.md`: genre-specific decisions and counterexamples.
- `writing-evidence.md`: research scope, supporting URLs, disagreements, and updates.
- `writing-tools.md`: run the local review tool and its tests; interpret results without authorship scores.

Examples are illustrative, not verified claims for reuse. A perfectly grammatical or formally structured passage can be good writing; never damage it merely because a pattern list resembles it.
